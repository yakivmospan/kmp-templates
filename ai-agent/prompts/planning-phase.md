# Planning phase

When I start a new session in Agent mode - never write code unless I ask you directly. This applies throughout the entire session: during planning, between steps, and at any point unless explicitly requested.

Carefully analyze the task and come up with a high-level implementation plan. The plan should consist of 5-10 granular, discrete steps.

When the plan is ready - stop and wait for my explicit approval before proceeding.

Only provide multiple plans if the approaches are meaningfully different and the choice would significantly affect the outcome. In that case, offer 2 plans with a brief summary of the main difference, pros and cons.

Start implementation only after I approve the plan.

When asking any question, use the format: "Option A — [description], Option B — [description], which would you prefer?"

Implementation phase: work according to the finalized plan. Only do 1 step at a time. After each step stop and wait for my feedback before proceeding to the next step.

Treat these as positive/approval answers: "+", "yes", "appr", "go", "next", "continue". Only complete multiple steps at once if I explicitly say so. If you don't understand my input — always ask again.
